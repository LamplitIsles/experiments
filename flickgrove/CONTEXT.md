# FlickGrove

FlickGrove 管理用户与 Orc、Worker 的协作会话。会话的存在和工作状态独立于用户是否打开访问界面。

## Language

**会话组织组（Org group）**：
按会话项目仓库的 owner 名称归集的会话树集合；名称忽略大小写，并跨 GitHub、Forgejo 合并，个人 owner 同样适用。它是导航归类，不是账号身份或权限边界。
_Avoid_：手动工作分组、平台组织身份、Project

**项目（Project）**：
在一个项目执行环境中登记、为 Agent 会话提供工作目录的项目。同一别名在不同环境中可以对应不同 checkout；项目与会话组织组分别表达。
_Avoid_：会话组织组、会话树

**会话执行后端**：
一个 Agent 会话创建时选定、恢复时继续使用的执行引擎，例如 Codex 或 Pi。同一会话树的成员可以使用不同后端；后端不改变成员的角色与所属关系。
_Avoid_：模型提供方、角色、执行主机

**会话模型选择**：
会话执行后端内选定的模型及其提供方。它与执行后端分别表达，同名模型不意味着相同的后端或账号。
_Avoid_：执行后端、账号、角色

**周额度周期**：
账号服务定义的连续七天额度窗口，以该账号的重置时刻划分边界；它不等于自然周。
_Avoid_：本自然周、日历周

**周期已过比例**：
当前周额度周期中已过去的时间占完整周期的比例，与额度消耗分别表达。
_Avoid_：已用额度、剩余额度

**已用周额度**：
账号在当前周额度周期中已消耗的额度比例，与周期已过时间分别表达。
_Avoid_：剩余周额度、周期已过比例

**剩余周额度**：
账号在当前周额度周期中尚可使用的额度比例，与周期剩余时间分别表达。
_Avoid_：剩余时间、周期已过比例

**Orc（协调者）**：
用户直接发出指令的 agent，负责调查、讨论、派工与管理协作；所有代码开发和修复交给 Worker，不设小修复例外。职责边界不等同于文件写入权限。
_Avoid_：主节点、管理员

**Worker（工作者）**：
接受所属 Orc 派工的 agent；用户可以阅读其会话，并通过 Orc 给它指令。
_Avoid_：独立助手、子进程

**Reviewer（审查者）**：
受委派对指定工作进行独立只读审查的 agent，通过阅读代码和已有证据提出结论；不修改被审查的工作，也不运行测试、构建或浏览器验证。
_Avoid_：实现 Worker

**Researcher（调查者）**：
受所属 Orc 委派调查一个明确、有边界的问题，异步返回已验证事实与来源、解释/猜测、冲突、未知项和后续线索。Orc 负责综合、最终推荐与 FlickNote 存档；Researcher 不开发代码、不写仓库或 FlickNote、不创建 agent。职责约束不等同于硬权限隔离。
_Avoid_：Reviewer、实现 Worker、最终推荐者

**Researcher 配置快照**：
创建时捕获的模型、推理力度与职责文本，随身份、owner、调查问题、报告及原生 thread 持久保留。跟进和恢复沿用；后续配置变化仅影响新 Researcher。
_Avoid_：审查目标、实时全局配置

**Agent 会话**：
一个 Orc、Worker、Reviewer 或 Researcher 持有的持续对话与工作上下文。关闭详情或访问界面不等于关闭 Agent 会话。
_Avoid_：浏览器会话、窗口

**历史会话**：
执行主机上已保存、可供查找和阅读的原生会话。其历史记录是否可见与其是否在 Grove 中打开分别表达。
_Avoid_：已关闭会话、浏览器历史

**会话阅读缓存**：
访问设备保留的会话内容副本，用于重新打开或暂时断联时继续阅读。清理副本不删除执行主机上的历史会话，也不代表消息提交已获得确认。
_Avoid_：历史会话、本地待确认项

**恢复会话**：
在原实例主机上继续同一个历史会话，保留原项目执行环境、对话和已有协作角色及所属关系。恢复不隐式发送一条指令。
_Avoid_：新建会话、转换角色

**自动继续**：
执行主机恢复可用后，原会话继续处理已经确认接收但尚未完成的工作。它不产生新的消息提交，也不授权重新发送接收结果未知的提交。
_Avoid_：重发、再次提交、恢复失败消息

**输入撤回**：
已接收的排队输入因停止而结束等待，之后不再交给模型处理。原接收确认仍然成立；撤回结果与接收结果分别表达。
_Avoid_：提交被拒绝、尚未接收、自动重试

**会话树**：
一个 Orc 与它所属的全部 Worker、Reviewer 和 Researcher 的协作集合。一棵会话树归属一个本地实例，并保持相同的项目执行环境。
_Avoid_：Session、工作区

**关闭会话树**：
用户主动表达结束整棵会话树后续协作的意图，覆盖 Orc 与其所属成员，同时保留历史及所属关系。关闭不代表任务完成、PR 合并或部署；它与退出会话详情、离开访问界面或停止当前任务分别表达。工作静止本身不表达关闭意图。
_Avoid_：返回、停止

**用户交接**：
Orc 已向用户交付当前结果，并明确等待用户下一步指示。它与执行暂歇、问题、发送确认和关闭会话分别表达。
_Avoid_：idle、阶段进度、任务关闭

**停止当前任务**：
中断 Orc 当前一轮执行，不结束 Agent 会话，也不隐式停止所属 Worker 的工作。
_Avoid_：关闭会话树、退出

**执行主机**：
持有 Agent 会话和执行后端的实例主机；它可以与项目执行环境所在设备不同。访问界面是否保持连接不决定这些会话是否存在。
_Avoid_：项目执行环境、访问设备

**实例主机**：
运行本地实例、持有会话树与协作归属的机器。项目工作目录位于其他设备时，会话仍归属这个实例。
_Avoid_：项目执行环境、访问设备

**项目执行环境**：
提供项目登记、工作目录和项目命令执行的环境；它可以位于实例主机或另一台设备。它不拥有会话树，也不等同于会话执行后端。
_Avoid_：实例主机、会话执行后端、访问设备

**本地实例**：
当前打开的 FlickGrove 服务，持有会话树、模型配置和历史，并提供其可用项目执行环境中的项目。浏览器只连接同源实例；项目远程执行不意味着连接或聚合其他 Grove 实例。
_Avoid_：Peer、入口节点、汇总入口

**访问连接状态**：
访问设备与当前实例的连接状态；断联保留最后已知阅读数据，不表示本地执行停止。重连只核对原提交身份，不自动重发。
_Avoid_：执行中断、多主机连接

**访问设备**：
用户用来查看会话和发出指令的设备；它可以与执行主机是同一台机器，也可以是另一台机器。
_Avoid_：执行主机、会话所有者

**新建会话偏好**：
访问设备为下次创建会话保存的Orc／Worker 模型、推理力度与 Fast 选择。偏好不是执行主机的全局设置，也不改变已有会话。
_Avoid_：全网默认设置、Hub 默认设置、Peer 全局设置

**会话执行配置**：
创建会话时捕获、由本地实例 与原生 thread 持有的模型、推理力度与 Fast 选择。用户可在当前打开的 Orc／Worker 详情单独保存模型与推理力度；Fast 策略属于其会话树，作用于开放且可修改的成员和未来 Worker，受各模型能力约束。下一次新执行轮生效；执行中补充保留当前轮配置。修改不改变其他树、模型／推理默认配置或浏览器新建偏好。后续浏览器偏好变化或浏览器关闭不改变该会话的执行配置。
_Avoid_：浏览器偏好、全局默认设置

**会话树 Fast 策略**：
所属 Orc 持有的期望速度选择，适用于树内支持 Fast 的开放成员和未来 Worker。它与每个原生 thread 已确认的下一轮执行配置、正在执行的配置分别表达。成员无法确认时，已确认值仍为事实，用户显式重试先读取原生配置。
_Avoid_：逐会话 Fast、全局速度设置、整树原子保存

**实例限定身份**：
稳定实例 ID 与本地 Agent ID 共同限定阅读缓存、草稿、所属关系和待确认操作。保留既有身份以核对原回执，不代表远程路由或访问凭据。
_Avoid_：远程主机选择、Peer token

**本地待确认项**：
访问设备保留的、尚未获得确定结果的消息提交记录。本地结果为 pending（发送中），连接恢复后按原身份核对，不自动重发；null 核对结果不授权恢复或推断失败。
_Avoid_：已发送消息、服务端历史

**会话导航项**：
用户在会话树列表中通过快捷键定位的唯一当前会话项。详情打开时，导航项与详情指向同一个会话；它与 Agent 的工作状态分别表达。
_Avoid_：活动 Agent、运行节点

**待回答问题**：
Agent 提交给用户、尚未确认答案的问题。正在填写的答案属于该问题；新问题到来不改变已有问题及其草稿的身份。
_Avoid_：当前执行任务、消息草稿

**问题批次**：
同一个原生 Question.itemId 中按 index 排列的问题集合；其答案提交保留原 question IDs 和 operation ID，新到问题不改变既有批次身份。
_Avoid_：当前全部待答问题、文本相同的问题集合

**问答回看**：
从原生会话记录按 item ID 或答案 clientId 对应的提交身份，读取原问题、选项及已确认答案。它不创建另一份历史记录，也不再次提交答案。
_Avoid_：重新作答、独立问题历史

**Skill 候选**：
供用户搜索并插入消息的已启用 skill。本机项目沿用该项目的原生候选；远程项目仅选择实例主机的集中 skills 与 Grove 内置工作流，不列出远端项目候选。原生执行加载远端项目 AGENTS/skills 与候选搜索分别表达。选择候选只准备消息中的调用名称，发送消息后才发出调用指令。
_Avoid_：自动执行、跨设备汇总、原生自动上下文

**内置 Skill 快捷项**：
消息输入区固定提供的工作流调用入口，与可搜索的 Skill 候选分别表达。
_Avoid_：Skill 候选、自动执行

**语音输入**：
为当前 Orc 的未发送消息草稿补充可编辑文字的输入方式；用户决定何时发送识别后的消息。
_Avoid_：语音消息、自动发送

**消息提交**：
用户向一个 Orc 发出的单次输入，具有持续可核对的身份；连续发送的每条输入分别是一项提交。它与一次执行轮次、一次回答分别表达。
_Avoid_：请求、执行轮次、任务完成

**提交标识（operation ID）**：
消息或答案提交的稳定身份，用于核对接收结果并识别同一次提交。相同内容的两次独立提交具有不同身份；它与原生会话内容项的身份分别表达。
_Avoid_：前端消息 ID、原生内容项标识

**原生内容项标识（item ID）**：
执行后端原生会话中一个内容项的身份，可用于识别历史读取与实时通知中的同一个原生内容项。它不直接证明该项对应哪一次 Grove 提交。
_Avoid_：提交标识、执行轮次标识

**发送确认**：
执行主机对消息提交处理结果的确认。公开回执仅 accepted（既有原生接收确认）或 rejected（明确未接收）；lookup 无确定结果返回 null。本地结果为 pending／accepted／rejected。保存发送记录或图片上传成功不等于接收；确认已接收不代表 Orc 已完成工作，也不代表输入已被模型消费。
_Avoid_：回答完成、连接成功、消费确认

**消息图片**：
用户作为消息提交一部分交给 Orc 的图片，与该提交的文字共同属于原会话。图片准备完成与整条消息被执行主机接收分别表达。
_Avoid_：独立消息、已发送附件

**图片草稿**：
属于某个 Orc 会话、尚未提交的消息图片。切换当前查看的会话不改变它的归属。
_Avoid_：共享剪贴板、全局附件

**执行中补充**：
Orc 正在工作时，用户新发的消息立即补充到当前执行轮。多条补充分别保留自己的提交身份，不等待上一条指令完成后再开启独立任务。
_Avoid_：等待执行、下一轮任务、自动重发

**执行上下文**：
每个 Agent 会话所持有的项目环境、角色指令和对话状态。同一执行主机上的会话可以共享执行服务，仍各自保有身份与工作状态；关闭一个会话不结束其他会话。
_Avoid_：独立子进程、共享身份

**会话目录分支**：
Agent 会话工作目录所属 Git checkout 当前检出的分支。它属于该目录的现状；共用同一 checkout 的会话看到同一个分支，不代表各会话私有或创建时的分支。
_Avoid_：会话专属分支、创建分支、任务分支

**模型容量等待**：
Agent 当前执行因所选模型暂时无法接纳而等待恢复。它与执行主机断联、消息是否被接收、执行最终失败分别表达；只有仍会继续尝试的执行才处于等待中。
_Avoid_：主机离线、发送失败、任务完成

**文件预览**：
从原消息所属实例 读取 Agent 生成文件的临时阅读界面。收起预览不关闭会话，也不撤销已打开新标签页在有效期内的访问。
_Avoid_：文件管理器、浏览器会话、公开分享

**预览资源根**：
经验证的入口文件所在 canonical 目录；预览只读取此目录及子目录内受支持的常规文件。它与 Agent 会话工作目录和整台主机文件系统分别表达。
_Avoid_：全盘静态目录、代理服务

**审查目标**：
一次审查所针对的审查轴、原始 spec、固定比较点和被审查 HEAD；旧目标的结论不代表新 HEAD 已通过。
_Avoid_：当前分支已通过、任务完成

**Reviewer 配置快照**：
一个 Reviewer 创建时捕获的模型、推理与职责内容，属于该持续会话，复审沿用；后续配置变化只影响新 Reviewer。
_Avoid_：Worker 默认配置、实时全局配置

**Orc 职责快照**：
一个 Orc 创建或首次明确恢复时捕获的可配置职责内容，属于该持续会话；后续配置变化只影响新会话，固定协作职责始终适用。
_Avoid_：实时全局提示词、模型配置

**原生提交关联标识（clientId）**：
原生用户内容项保留的 Grove 投递身份，由发送时的 clientUserMessageId 传入。它把一条内容项关联到投递来源与报告者；同轮或同正文不构成关联，也不保证原生幂等或模型消费。
_Avoid_：内容项标识、轮次标识、消费确认

**近期阅读窗口**：
本地实例 在实时会话详情中提供并持续滑动的有界原生内容范围。窗口之外的内容仍属于原生会话，可通过历史阅读取回；移出窗口不表示消息被删除。
_Avoid_：完整会话、固定历史分界、永久实时尾部

**历史阅读页**：
本地实例 按原生内容项身份和阅读预算提供的早期会话内容及该页需要的来源信息。下一游标指向未返回内容的准确位置；超大单项保留原身份并可读取完整正文。
_Avoid_：执行轮组替换、第二份 transcript、正文截断
