# FlickGrove

FlickGrove 管理用户与 Orc、Worker 的协作会话。会话的存在和工作状态独立于用户是否打开访问界面。

## Language

**Orc（协调者）**：
用户直接发出指令的 agent，负责协调和管理属于自己的 Worker。
_Avoid_：主节点、管理员

**Worker（工作者）**：
接受所属 Orc 派工的 agent；用户可以阅读其会话，并通过 Orc 给它指令。
_Avoid_：独立助手、子进程

**Reviewer（审查者）**：
受委派对指定工作进行独立审查的 agent；审查职责与 Worker 的实现派工职责分别表达。
_Avoid_：实现 Worker

**Agent 会话**：
一个 Orc 或 Worker 持有的持续对话与工作上下文。关闭详情或访问界面不等于关闭 Agent 会话。
_Avoid_：浏览器会话、窗口

**会话树**：
一个 Orc 与它所属的全部 Worker 的协作集合。一棵会话树完整归属一台执行主机。
_Avoid_：Session、工作区

**关闭会话树**：
结束一棵会话树的后续协作。它与退出会话详情、离开访问界面或停止当前任务分别表达。
_Avoid_：返回、停止

**停止当前任务**：
中断 Orc 当前一轮执行，不结束 Agent 会话，也不隐式停止所属 Worker 的工作。
_Avoid_：关闭会话树、退出

**执行主机**：
提供项目工作环境并持有 Agent 会话的机器。访问界面是否保持连接不决定这些会话是否存在。
_Avoid_：客户端、远程设备

**访问设备**：
用户用来查看会话和发出指令的设备；它可以与执行主机是同一台机器，也可以是另一台机器。
_Avoid_：执行主机、会话所有者

**汇总入口**：
用户统一查看不同执行主机上的会话树并发出指令的访问入口。汇总不改变会话树的归属。
_Avoid_：执行主机、会话所有者

**会话导航项**：
用户在会话树列表中通过快捷键定位的唯一当前会话项。它表示下一次打开或展开操作的目标，与已打开的会话详情及 Agent 工作状态分别表达。
_Avoid_：活动 Agent、运行节点

**Skill 候选**：
当前会话的项目环境中，供用户搜索并插入消息的已启用 skill。选择候选只准备消息中的调用名称，发送消息后才发出调用指令。
_Avoid_：自动执行、全主机技能库
