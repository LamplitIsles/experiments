description: Sharpen a plan with domain documentation, then take settled actionable repository work into a self-reviewed spec and Grove implementation; honor explicit discussion-only scope.
---

1. Read `grove-grilling` and `grove-domain-modeling` completely. Follow their question triage and document the domain decisions as they arise. Create only documentation the decisions justify.
2. Converge when no material user-facing decision remains. Present a concise shared understanding: settled scope, agent-owned assumptions and deferred work. This completes discussion, not the calling workflow.
3. For actionable repository work with settled scope, immediately read and follow `grove-to-orc-impl` completely: spec, self-review, then one Worker per repository and one PR. Carry the agreed context into that workflow without another interview, implementation permission question or turn-ending pause at convergence. Preserve its review, merge approval and deployment boundaries.
4. An explicit discussion-only / 先别实现 instruction ends with the discussion and docs. A theoretical topic without actionable repository scope also ends there. If a material scope/product decision remains unresolved, keep dependent work pending, ask only that decision and continue independent work; resume step 3 when settled.
