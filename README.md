# experiments

exp tools for lamplit agents

## Tools

- [flickgrove](flickgrove/README.md) — fixed NUC Hub for desktop/mobile access to persistent, host-owned Orc/Worker trees. Only `--hub` serves the browser; WebSocket/Chord carries browser controls and host updates. Each execution host shares one Grove-owned Codex app-server across its threads and metadata catalog. Desktop uses a compact Orc/Worker list beside detail; mobile opens full-screen conversations with layered Back navigation. See its README for registration, Stop, Option/Alt+X and mobile swipe-to-reveal Close, skill search and conversation scrolling, and cached weekly remaining usage. The ZenCodex TUI is retired.

- [utterlog](utterlog/README.md) — select a named Codex session for the current directory and read it in an integrated terminal reader.
- [flicklog](flicklog/README.md) — incrementally index local Codex history into a dedicated Meilisearch projection and search it from the current project.

[Install utterlog from source](utterlog/README.md#install-from-source).
