# experiments

exp tools for lamplit agents

## Tools

- [flickgrove](flickgrove/README.md) — persistent Orc/Worker/Reviewer trees with symmetric execution Peers. Every Peer serves the browser, which connects directly to each configured host over authenticated WebSocket/Chord and bounded image HTTP. Each Peer shares one Grove-owned Codex app-server across its threads. Desktop uses a compact session list beside detail; mobile opens full-screen conversations with layered Back navigation. Local image/HTML/Markdown links open a wide sandboxed preview on their original execution Peer. See its README for managed workflow skills, configurable independent Reviewer profiles, file previews, image messages and per-conversation drafts, wide single-question drawers and durable batch answers, session shortcuts, host registration, Stop/Close, skill search, history and weekly remaining usage. The ZenCodex TUI is retired.

- [utterlog](utterlog/README.md) — select a named Codex session for the current directory and read it in an integrated terminal reader.
- [flicklog](flicklog/README.md) — incrementally index local Codex history into a dedicated Meilisearch projection and search it from the current project.

[Install utterlog from source](utterlog/README.md#install-from-source).
